# 🛒 Ekita Grocery Store

A responsive online grocery store web application specializing in Nepalese cuisine and daily household essentials. Built to provide users with an intuitive shopping experience, product browsing, and interactive customer feedback.

🔗 **Live Demo:** [ekitagrocery.netlify.app](https://ekitagrocery.netlify.app)

---

## ✨ Features
- **Multi-Page Navigation:** Dedicated pages for Home, Grocery Items (`grocery.html`), About Us (`about.html`), Animations (`animation.html`), and Customer Feedback (`feedback.html`).
- **Product Showcase:** Organized display of authentic Nepalese groceries and daily essentials with product imagery.
- **Interactive UI:** Smooth transitions, responsive layout across desktop and mobile devices, and user feedback forms.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting & Deployment:** Netlify
- **Version Control:** Git & GitHub
